## 5. Important new loader architecture risk

Part52 [#455 public-safe engineering checkpoint](https://github.com/CosmicCuddle/N-Questie/pull/455#issuecomment-6544010379) found:
- `Compat/NQuestieCustomQuestLoader.lua` requires a referenced quest's NPC/object/**item** sources to be present in `npcData/objectData/itemData`, but the custom loader registers correction callbacks only for `questData/npcData/objectData`.
- `Compat/Compat.lua` iterates `correctionsRegistry` via `pairs`, which does **not** guarantee cross-group ordering.
- A naive quest + item correction risks validation before item source provision and memoization of rejection. A future **deterministic, complete, collision-safe source-provision stage** must be designed and reviewed before claiming the pilot works.
- This is source research, **not** proof of a running-client bug or an authorised fix. Preserve original addon data and previously installed quest 2001.

The [Part52 #456 test](https://github.com/CosmicCuddle/N-Questie/pull/456) specifically distinguishes AQ War Effort option suppression, manual character hide, compiled `QuestPointers` omission and `IsDoable` suppression. It does not verify real user settings or real pilot quests. Do not globally disable AQ, progression or hiding filters to make pins appear.
